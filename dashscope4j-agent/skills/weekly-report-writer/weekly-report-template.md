# 周报标准模板

**版本**: 1.1  
**最后更新**: 2026-03-26

---

```markdown
# 周报 - [姓名] - [起始日期] 至 [结束日期]

## 📅 写在前边
- **时间**：[具体日期，如 2026.03.25]
- **天气**：[城市] [天气状况] (数据来源：联网搜索)
- **心情/状态**：[可选，一句简短的状态描述]

## 一、本周工作总结

### 1.1 ✅ 已完成工作
- [动词开头] [任务名称]：[量化成果/具体产出]
- ...

### 1.2 🔄 进行中工作
- [任务名称]：进度 [XX]% | 预计完成：[日期] | [当前阻塞点/风险，若无则填无]

## 二、关键成果与亮点 (Key Highlights)
> 💡 此处仅列出本周最有价值的 1-3 件事，强调对团队/业务的影响。
- [亮点 1]：通过 [手段]，实现了 [具体收益，如节省成本/提升性能]
- [亮点 2]：...

## 三、问题与挑战

### 3.1 🛠️ 已解决的问题
- [问题描述] -> [解决方案] -> [后续预防措施]

### 3.2 🆘 需要支持的问题
- [问题描述]：需要 [具体角色/部门] 提供 [具体支持内容]，期望在 [时间] 前解决。

## 四、下周计划 (Next Week Plan)

### 🔴 P0 (必须完成 - 影响上线/核心指标)
- [任务名称]

### 🟡 P1 (应该完成 - 重要但不紧急)
- [任务名称]

### 🟢 P2 (可以延后 - 优化/探索类)
- [任务名称]

## 五、其他说明
- [团队协作/个人成长/培训分享/资源推荐等]
```

---

**使用说明**:
- 方括号 `[...]` 表示需要替换的内容
- 所有标注为"可选"的字段可根据实际情况留空
- 保持 Markdown 格式以确保良好的可读性
