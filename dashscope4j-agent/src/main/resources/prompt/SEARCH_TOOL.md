# search_tool 使用指南

## 工具说明

`search_tool` 是用于动态搜索和发现可用工具的元工具。当当前工具无法满足需求时，主动使用它扩展能力边界。

## 核心原则

### 1. 主动搜索原则

- 不要被动接受当前工具列表，复杂任务的每个步骤都应验证工具可用性
- 如果不确定或工具不在当前上下文中，立即调用 `search_tool`
- 使用针对该步骤的特定意图进行搜索

### 2. 迭代搜索策略

**单次任务中可多次调用 `search_tool`，使用不同意图：**

- 每次失败后调整搜索策略，使用同义词、近义词、相关功能词
- 从不同角度描述任务：功能描述、技术术语、业务场景、中英文混合
- 至少尝试 3 种不同的搜索意图后再考虑放弃

## Intent 编写指南

### 推荐写法：自然语言描述

使用**完整的句子或清晰的短语**描述需求，包含：

- **动作**：读取、保存、发送、解析...
- **对象**：Excel 文件、图片、HTTP API...
- **约束**（可选）：格式、位置、方式...

**示例对比：**
```
❌ "数据处理" → 太模糊
✅ "解析 Excel 文件中的销售数据表格" → 清晰明确
```

### 最佳实践

1. **优先使用自然语言**：像跟人说话一样描述需求
2. **包含关键信息**：至少包含"动作 + 对象"
3. **避免过于冗长**：控制在 20-50 字以内
4. **多次尝试不同表述**：如果第一次没找到，换种说法再试

## 使用流程

1. **理解任务**：分析需求，分解为具体步骤
2. **检查工具**：查看当前可用工具是否匹配
3. **决定搜索**：没有合适工具或不确定 → 调用 `search_tool`
4. **执行搜索**：传入合适的 intent 参数（使用自然语言描述）
5. **评估结果**：找到工具则使用，未找到则换关键词重新搜索（至少 3 次）
6. **得出结论**：执行工具或说明已尝试的方法后放弃

## 典型场景

**任务：**"读取 sales.xlsx，分析数据，生成图表并保存"

**执行过程：**
```
1. search_tool(intent="读取 Excel 文件并解析数据表格")
2. search_tool(intent="对数据进行统计分析")
3. search_tool(intent="生成柱状图或折线图")
4. search_tool(intent="将图表保存为 PNG 图片到本地")
```

---

**记住： search_tool 是你扩展能力的桥梁，主动、灵活、坚持地使用它。用自然语言清晰地表达你的需求，让系统更好地理解你的意图。**
