# search_tools 使用指南

## 工具说明

`search_tools` 是一个特殊的元工具，用于动态搜索和发现可用的工具。当当前可用工具无法满足任务需求时，你必须主动使用它来扩展能力边界。

## 核心原则

### 1. 主动搜索原则

**不要被动接受当前可用的工具列表，要主动搜索更多可能性。**

- ❌ 错误：看到当前工具列表中没有匹配的，就直接放弃
- ✅ 正确：立即调用 `search_tools`，用相关关键词搜索更多工具

### 2. 多步任务必搜原则

**复杂任务通常需要多个步骤，每个步骤都需要验证工具可用性。**

- 对于每一个子任务，检查所需工具是否可用
- 如果不确定或工具不在当前上下文中，必须调用 `search_tools`
- 使用针对该步骤的特定意图进行搜索

例如：
```
任务："查询杭州天气并生成图片"

步骤 1: 需要天气数据
→ 调用 search_tools(intent="天气预报")
→ 得到 get_weather 工具
→ 执行获取天气

步骤 2: 需要生成图片
→ 调用 search_tools(intent="图像生成")
→ 得到 generate_image 工具
→ 执行生成图片
```

### 3. 永不放弃原则

**如果找到的工具不可用或执行失败，不要立即判定任务无法完成。**

- 🔍 **工具执行失败时**：
  - 不要直接宣布失败
  - 继续思考其他可能的解决方案
  - 尝试使用不同的关键词/意图再次搜索工具
  - 考虑是否存在替代工具可以达成相同目标

- 💡 **示例场景**：
  - 场景 A: `get_weather` 工具执行失败 → 尝试搜索 `weather_api`、`climate_data`、`forecast_service` 等其他天气工具
  - 场景 B: `generate_image` 工具不可用 → 尝试搜索 `image_creator`、`visual_generator`、`picture_maker` 等其他绘图工具
  - 场景 C: 某个 API 工具报错 → 尝试搜索其他提供类似功能的 API 工具

- ✅ **正确做法**：
  ```
  第一个工具失败了，但这不代表任务无法完成。
  让我尝试搜索其他可以提供相同功能的工具。
  → 调用 search_tools(intent="气候数据 温度信息")
  → 找到 climate_service 工具
  → 尝试使用新工具
  ```

- ❌ **错误做法**：
  ```
  工具失败了，我无法完成这个任务。
  抱歉，我无法帮助你。
  ```

- ⚠️ **何时可以放弃**：
  - 你已经尝试了所有合理的替代方案（至少 3 种不同的搜索意图）
  - 所有可用的工具都已尝试且全部失败
  - 确认环境中确实没有任何工具可以完成该步骤
  - 该步骤是任务的关键前置条件，无法绕过
  - 放弃时必须说明已经尝试过哪些工具和方法

### 4. 迭代搜索策略

**你可以在单次任务中多次调用 `search_tools`，使用不同的意图。**

- 每次失败都是一次学习机会，调整你的搜索策略
- 使用同义词、近义词、相关功能词作为新的搜索意图
- 从不同角度描述任务，扩大搜索范围

**搜索关键词策略：**
- 功能描述：如 "文件保存"、"图片下载"
- 技术术语：如 "file write"、"HTTP download"
- 业务场景：如 "本地存储"、"网络资源获取"
- 中英文混合：如 "save file"、"下载图片"

例如：需要保存图片
```
第 1 次搜索: search_tools(intent="保存图片")
第 2 次搜索: search_tools(intent="文件写入")
第 3 次搜索: search_tools(intent="本地存储")
第 4 次搜索: search_tools(intent="file write")
第 5 次搜索: search_tools(intent="download")
```

## 工作流程

### 标准流程

1. **理解任务**：分析用户需求，分解为具体步骤
2. **检查工具**：查看当前可用工具是否匹配
3. **决定搜索**：
   - 如果有合适工具 → 直接使用
   - 如果没有或不确定 → 调用 `search_tools`
4. **执行搜索**：传入合适的 intent 参数
5. **评估结果**：
   - 如果找到合适工具 → 使用该工具执行
   - 如果未找到 → 更换关键词重新搜索
6. **重复迭代**：直到找到工具或穷尽所有可能（至少 3 次）
7. **得出结论**：执行工具或说明限制

### 决策树

```
遇到任务
  ↓
当前有合适工具？
  ├─ 是 → 直接使用工具
  └─ 否 → 调用 search_tools
           ↓
      找到工具？
        ├─ 是 → 使用该工具
        │        ↓
        │     执行成功？
        │       ├─ 是 → 继续下一步
        │       └─ 否 → 重新搜索（换关键词）
        └─ 否 → 已尝试 ≥3 次？
                 ├─ 是 → 说明限制，放弃
                 └─ 否 → 重新搜索（换关键词）
```

## 最佳实践

### 1. 搜索时机

**应该调用 search_tools：**
- 开始新任务，不确定有哪些工具可用
- 当前工具列表中没有明显匹配的工具
- 工具执行失败，需要寻找替代方案
- 任务的某步骤需要特定能力（文件操作、网络请求等）

**不应调用：**
- 已有明确可用的工具可以直接使用
- 刚搜索过相同关键词且结果为空（应换关键词再搜）

### 2. 关键词选择

**好的关键词：**
- 具体明确：如 "Excel 解析" 而非 "数据处理"
- 多角度：准备 3-5 个不同角度的关键词
- 包含同义词：中英文、专业术语、通俗说法
- 功能导向：描述要做什么，而非怎么做

**示例：**分析销售数据 → "Excel 解析"、"表格处理"、"数据分析"、"spreadsheet parse"、"CSV reader"

### 3. 结果处理

- 仔细阅读每个工具的描述
- 选择最匹配的工具
- 如果都不匹配，重新搜索（换关键词）

### 4. 失败处理

1. 分析失败原因（参数错误？工具不存在？）
2. 参数问题 → 修正参数重试
3. 工具问题 → 重新搜索替代工具
4. 记录已尝试的工具和关键词，避免重复

## 注意事项

1. **search_tools 是你的核心能力**：善用它能解决绝大多数任务
2. **不要浅尝辄止**：至少尝试 3 种不同的搜索意图
3. **保持灵活性**：同一个任务可能有多种实现方式
4. **记录尝试历史**：避免重复搜索相同的关键词
5. **诚实报告**：放弃时必须说明已经尝试过哪些方法

## 典型场景

### 场景 1：多步骤任务

**任务**："读取 sales.xlsx 文件，分析数据，生成图表"

**执行过程**：
```
1. 需要读取 Excel 文件
   → search_tools(intent="Excel 解析")
   → 找到 read_excel 工具
   → 执行读取

2. 需要分析数据
   → search_tools(intent="数据分析")
   → 找到 analyze_data 工具
   → 执行分析

3. 需要生成图表
   → search_tools(intent="图表生成")
   → 找到 create_chart 工具
   → 执行生成
```

### 场景 2：工具失败后的重试

**任务**："下载网络图片并保存"

**执行过程**：
```
1. 需要下载图片
   → search_tools(intent="图片下载")
   → 找到 download_image 工具
   → 执行下载 → 失败（网络错误）

2. 尝试替代方案
   → search_tools(intent="HTTP 请求")
   → 找到 http_get 工具
   → 使用 http_get 下载 → 成功

3. 需要保存图片
   → search_tools(intent="文件写入")
   → 找到 text_file$write 工具
   → 保存图片路径信息
```

### 场景 3：穷尽搜索后放弃

**任务**："实时语音转文字"

**执行过程**：
```
1. 第 1 次搜索: search_tools(intent="语音识别")
   → 未找到

2. 第 2 次搜索: search_tools(intent="speech to text")
   → 未找到

3. 第 3 次搜索: search_tools(intent="音频转录")
   → 未找到

4. 结论：
   抱歉，我尝试了多种搜索关键词（"语音识别"、"speech to text"、"音频转录"），
   但环境中没有可用的语音转文字工具。建议您使用专门的语音识别服务。
```
