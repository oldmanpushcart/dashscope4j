# search_tools 使用指南

## 工具说明

`search_tools` 是用于动态搜索和发现可用工具的元工具。当当前工具无法满足需求时，主动使用它扩展能力边界。

## 核心原则

### 1. 主动搜索原则

- 不要被动接受当前工具列表，复杂任务的每个步骤都应验证工具可用性
- 如果不确定或工具不在当前上下文中，立即调用 `search_tools`
- 使用针对该步骤的特定意图进行搜索

### 2. 迭代搜索策略

**单次任务中可多次调用 `search_tools`，使用不同意图：**

- 每次失败后调整搜索策略，使用同义词、近义词、相关功能词
- 从不同角度描述任务：功能描述、技术术语、业务场景、中英文混合
- 至少尝试 3 种不同的搜索意图后再考虑放弃

**示例：**需要保存图片
```
第 1 次: search_tools(intent="保存图片")
第 2 次: search_tools(intent="文件写入")
第 3 次: search_tools(intent="本地存储")
第 4 次: search_tools(intent="file write")
```

## 使用流程

1. **理解任务**：分析需求，分解为具体步骤
2. **检查工具**：查看当前可用工具是否匹配
3. **决定搜索**：没有合适工具或不确定 → 调用 `search_tools`
4. **执行搜索**：传入合适的 intent 参数
5. **评估结果**：找到工具则使用，未找到则换关键词重新搜索（至少 3 次）
6. **得出结论**：执行工具或说明已尝试的方法后放弃

## 关键词策略

**好的关键词特征：**
- 具体明确："Excel 解析" 优于 "数据处理"
- 多角度：准备 3-5 个不同角度的关键词
- 包含同义词：中英文、专业术语、通俗说法
- 功能导向：描述要做什么，而非怎么做

**示例：**分析销售数据 → "Excel 解析"、"表格处理"、"数据分析"、"spreadsheet parse"、"CSV reader"

## 典型场景

**任务：**"读取 sales.xlsx 文件，分析数据，生成图表"

**执行过程：**
```
1. 需要读取 Excel 文件
   → search_tools(intent="Excel 解析")
   → 找到 read_excel 工具 → 执行读取

2. 需要分析数据
   → search_tools(intent="数据分析")
   → 找到 analyze_data 工具 → 执行分析

3. 需要生成图表
   → search_tools(intent="图表生成")
   → 找到 create_chart 工具 → 执行生成
```
